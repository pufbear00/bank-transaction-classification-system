# 银行流水分类系统

这是独立的本地副本，保留银行流水导入、分类、汇总报表、账户管理和摊销等源码。没有历史业务记录、银行账号清单、上传附件、公司主体预设、密钥或 Git 历史。初次启动只创建空表，不导入任何种子业务资料。

## 隔离方式

- 原 PostgreSQL 连接改为本目录 `backend/.local/bank-demo.sqlite3`；不会读取环境中的 `DATABASE_URL` 或任何 `.env`。
- 删除云端 AI 分类实现，只保留本地关键词分类；规则需自行使用虚构数据创建。
- 删除网络汇率连接器与后台同步任务；同步接口明确返回禁用。非 CNY 交易需要先手动添加该日期汇率，不用猜测汇率替代。
- 前端默认只连接 `127.0.0.1:8093`；后端只监听本机。没有原服务器部署、备份恢复、定时任务或初始化真实数据脚本。
- 公司识别改为本地自定义账户匹配，无法识别时显示“未指定主体”；不保留原公司名称和实体关系。

## 本地启动

需要 Python 3.12、Node.js 20+ 和 npm。依赖安装会从软件包仓库下载通用依赖，不会连接原业务系统。

在 `backend` 目录中，创建独立 Python 虚拟环境并启动：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --only-binary=:all: -r requirements.txt
.venv/bin/python run_local.py
```

在另一个终端进入 `frontend`：

```sh
npm ci --ignore-scripts
npm run dev
```

打开 `http://127.0.0.1:5193`。本版本不附带预装依赖、预构建前端或数据库；数据库会在首次运行时生成在新副本内。后续手工输入/上传的数据会保存在本副本中，演示时只能使用虚构资料。
